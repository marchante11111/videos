# Estudio – Privacy Policy

Estudio is a private tool used only by its owner to upload and schedule videos to the owner's own YouTube channels through the YouTube Data API.

- It accesses only the owner's YouTube account, with the owner's explicit authorization.
- It does not collect, store, sell or share data from any other user.
- Access tokens are stored privately and used only to upload and schedule the owner's videos.
- Access can be revoked at any time at https://myaccount.google.com/permissions

Uses YouTube API Services: https://www.youtube.com/t/terms · Google Privacy Policy: https://policies.google.com/privacy
